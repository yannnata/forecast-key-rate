## 3. Обоснование

1. **Инфляционные риски.** Банк России проводит денежно-кредитную политику, направленную на поддержание ценовой стабильности. При сохранении инфляционного давления регулятор может отказаться от дальнейшего снижения ставки. — [Банк России: инфляция](https://www.cbr.ru/hd_base/infl/)

2. **Влияние ставки на экономическую активность.** Высокие процентные ставки увеличивают стоимость заёмного капитала для предприятий и населения. Снижение ставки способно стимулировать инвестиции и потребительский спрос, однако одновременно может усилить инфляционное давление. — [Банк России: денежно-кредитная политика](https://www.cbr.ru/dkp/)

3. **Необходимость устойчивого замедления инфляции.** Для снижения ставки важны не только текущие показатели инфляции, но и прогноз её дальнейшей динамики. Если инфляционные ожидания останутся повышенными, регулятор может предпочесть выжидательную позицию. — [Банк России: аналитика](https://www.cbr.ru/analytics/)

4. **Неопределённость внешнеэкономических условий.** Изменения валютного курса, внешней торговли и бюджетных расходов способны влиять на инфляцию. Эти факторы затрудняют прогнозирование решений Банка России. — [Минэкономразвития России](https://economy.gov.ru/)
